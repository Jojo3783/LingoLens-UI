## 功能願景

LingoLens 不只幫使用者看懂英文，也要讓使用者在理解、回看與複習的每一個時刻，能
立即聽見單字、片語與句子的自然發音。發音功能應直接融入英文內容本身，而不是變
成使用者需要另外尋找的播放器。

使用者看到想聽的英文文字時，直接點擊該文字即可播放。這讓單字、片語、完整句子
與 AI 產生的自然英文表達都能成為可互動的學習單位，逐步建立文字、意思與語感之
間的連結。

## 與前置功能的關係

F-007 在 F-006 完成後開始，直接重用前面功能已建立的畫面、資料與 typed English
content，不重新設計分析或學習流程：

- F-001 提供 History／Favorites 中已保存的完整內容。
- F-002 提供可辨識的英文單字、片語、例句與自然表達 typed fields。
- F-003 的 Cache-First 行為不受播放影響；播放不建立新的分析或 History。
- F-004／F-005 提供 Review 與個人化素材中的英文內容。
- F-006 提供浮動分析視窗與桌面快捷入口，F-007 只讓其中的英文內容可播放。

F-007 只新增跨頁面的播放能力、播放狀態與系統 TTS adapter；不得把播放行為放回
F-001～F-006 各自重複實作。

## 使用者價值

- 在浮動窗口、分析結果、History、Favorites 與 Review 中，都能隨時聽英文發音。
- 使用者可依需求播放單字、片語或整句，而不是只能聽整份內容。
- 不需要離開 LingoLens 去搜尋發音，理解與聆聽維持在同一個學習流程內。
- 複習時能先回想、再點文字確認發音與語調。

## 重要實作細項

### 點擊文字即播放

- 所有可播放內容必須以英文文字本身作為點擊目標；第一版不以獨立喇叭按鈕作為主要播放入口。
- 可播放單位至少包含英文單字、片語、完整英文句子，以及 AI 生成的自然英文表達。
- 點單字只播放該單字；點片語播放完整片語；點句子播放完整句子。
- 使用者點擊目前正在播放的文字時，應有可預期行為，例如從頭重播或停止；產品需採用一致規則。
- 點擊文字觸發播放，不預設自動播放，避免打斷閱讀或在不適合的場所突然發聲。

### 跨頁面體驗

- 浮動分析窗口：原始英文、關鍵片語與自然英文答案皆可直接點擊播放。
- 分析結果頁：主要英文答案、例句、單字與片語可直接點擊播放。
- History 與 Favorites：已保存內容中的英文摘要、關鍵片語與例句可直接點擊播放。
- Review：使用者可在回想前或揭示答案後，點擊英文內容確認發音與語調。

### 視覺、操作與無障礙

- 可播放英文文字需要有一致且可辨識的視覺提示，例如強調色、底線或互動樣式；不可只依賴顏色傳達可點擊性。
- 桌面使用者滑鼠移至可播放文字時，應看見互動回饋；鍵盤使用者也必須能聚焦與啟動播放。
- 每個可播放文字需有清楚的語意標籤，例如「播放 look forward to 的發音」。
- 正在播放的文字應顯示清楚但不干擾閱讀的播放中狀態。
- 拖曳選取文字必須維持可用，不得因點擊播放功能而使一般文字選取變得困難或容易誤觸。

### 播放生命週期與平台能力

- 全 App 同一時間只能播放一段語音；使用者點擊新的英文文字時，先前播放必須停止。
- 離開頁面、關閉浮動窗口、開始新的分析或 App 結束時，不得留下失去控制的背景播放。
- 需如實呈現播放中、停止、失敗與系統語音不可用等狀態。
- 第一版以英文系統 TTS 為主，並可提供簡單的速度調整；美式／英式口音、聲音選擇可留待後續。
- TTS 優先使用裝置或作業系統能力，不應為播放功能把英文內容送至 Codex CLI 或 OpenAI API。

### 資料與學習邊界

- TTS 文字必須來自明確的英文內容單位，不能模糊地自動朗讀整份分析報告。
- 音訊檔不需永久保存到 History、Favorites 或一般本機資料庫。
- 播放行為不等於已學會；學習狀態仍應主要依據使用者的複習回饋。
- 不得保存 API key、raw provider response、private log 或不必要的播放追蹤資料。

## 不在本功能範圍

- 錄音、使用者發音評分、語音辨識或口說教練。
- AI 聲音複製、自訂音色、真人語音市場或音訊雲端同步。
- 自動播放整份分析內容或自動播放每個新結果。
- 以播放次數判定熟悉度，或用 TTS 取代 F-004 的複習回饋。
